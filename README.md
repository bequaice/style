# Примерка

Локальная версия мобильного приложения без сервера на Expo SDK 57.
Сценарии для проверки командой описаны в [REVIEW.md](REVIEW.md).

## Что уже работает

- локальная регистрация: имя, обязательный телефон, аватар и автоматически созданный неизменяемый ID;
- пять вкладок: Мои примерки, События, Друзья, Уведомления, Профиль;
- отдельные списки своих и полученных событий с именем и аватаром автора;
- камера, предпросмотр, пересъёмка, максимум три снимка, подпись до 100 символов и часть образа;
- 15 минут голосования с первого фото, лайк/дизлайк и явное изменение оценки;
- настройка «Скрыть участников и оценки»: получатель видит только собственный голос, автор — все; в открытом режиме результаты и участники видны всем приглашённым;
- участники видят события только во время голосования (15 минут), автор — до часа с отправки; затем данные удаляются;
- новый образ сразу завершает прежнее голосование; прежнее событие исчезает у участников сразу и остаётся у автора до своего исходного срока удаления;
- локальные друзья: поиск по номеру/ID, запросы и автоматическое добавление зарегистрированных совпадений телефонной книги;
- именованные шаблоны получателей (например, «Семья»), редактирование и повторное использование;
- уведомления участникам о добавленном фото и автору о новых/изменённых оценках со ссылкой на соответствующий образ;
- сохранённые получатели, приглашения без продления таймера, выход, блокировка и локальные жалобы;
- собственный профиль с фото и переключатель тестовых ролей.

[Алгоритм импорта](CONTACT_IMPORT.md) описывает текущую локальную реализацию и границу будущего серверного этапа.

На iOS/Android данные хранятся в AsyncStorage и файлах приложения, в браузере — IndexedDB. Удаление просроченных данных выполняется во время работы и при следующем запуске. Сохранённые круги друзей остаются. Старая версия локальных данных переносится автоматически.

Настоящая авторизация, SMS, поиск реальных аккаунтов, обмен между устройствами, серверная проверка прав и push требуют сервера. Тестовые роли не являются авторизацией. Фото образа снимается камерой; галерея используется только для аватара. В браузере есть отдельно обозначенный тестовый снимок для проверки интерфейса.

## Запуск

```bash
npm install
npm run ios
```

Для Android после установки Android Studio:

```bash
npm run android
```

В браузере:

```bash
npm run web
```

Статическая сборка для Netlify:

```bash
npm run build:web
```

Готовые файлы появятся в папке `dist`. В репозитории также находится
`netlify.toml`, поэтому при подключении проекта через Git Netlify сам выполнит
сборку и опубликует результат.

## Проверки

```bash
npm test
npm run lint
npx tsc --noEmit
npx expo-doctor
npm run build:web
```

Тесты правил используют встроенный Node test runner (Node 22.13+ с поддержкой
TypeScript через `--experimental-strip-types`). Нативные разрешения настраиваются
только в `app.json`. После изменения нативных модулей примените конфигурацию:

```bash
npx expo prebuild --no-install
npm run ios
```

Папки `ios/` и `android/` генерируются Expo и не содержат ручных правок.
Реальную камеру и телефонную книгу нужно дополнительно проверить на физических
устройствах: браузер и iOS-симулятор не заменяют такую проверку.
