# Импорт телефонной книги

1. По нажатию пользователя запросить разрешение ОС. При отказе оставить поиск по номеру и ID.
2. Прочитать только номера телефонов; не изменять телефонную книгу. Имена из неё не использовать для отображения.
3. Удалить пробелы, скобки, дефисы; российский номер из 11 цифр с начальной 8 привести к 7. Отбросить некорректные номера и повторы.
4. Найти зарегистрированные профили по нормализованным номерам. Сейчас поиск выполняется только среди локальных тестовых профилей (`matchContactNumbers`). После подключения сервера нужен отдельный защищённый запрос совпадений с разрешением пользователя; простое хеширование номеров не обеспечивает анонимность.
5. Исключить собственный профиль и заблокированных пользователей. Найденные аккаунты автоматически добавить в друзья без встречного импорта. Повторный импорт не создаёт дубликаты и не удаляет уже существующих друзей.
6. Показывать имя, аватар, ID и телефон из аккаунта человека. Локальных переименований и чужого редактирования аватара нет.
7. Ненайденные номера не показывать как пользователей. Для ручного добавления по номеру отправлять запрос в друзья с принятием или отклонением.

До сервера телефонная книга не отправляется в сеть. Совпадения с настоящими аккаунтами, уникальность номера, подтверждение SMS, права доступа и доставка запросов появятся на серверном этапе. Нативное чтение контактов требует отдельной проверки на физическом телефоне.
